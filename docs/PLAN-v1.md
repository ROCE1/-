## 一、健身模块重构（第 1 项 · ✅ 0.5.0 已完成）

**独立页面，不混在今日任务里。** 顶部两个页签：力量日 / 有氧日。

### 轮换规则（已确认：B 方案）

力量日与有氧日**交替**，自动翻。实现：以一个基准日 `anchor`（首次设置的日期）计算，
`天数差 % 2 === 0` 为力量日，否则有氧日。用户可以手动临时切换到另一天（只影响当天显示）。

### 数据模型

```ts
type FitnessDay = 'strength' | 'cardio'

interface FitnessItem {
  id: string
  name: string            // 健身内容：卧推 / 跑步
  day: FitnessDay
  sets?: number           // 组数（力量）
  reps?: number           // 个数（力量）
  minutes?: number        // 时长（有氧）
  km?: number             // 距离（有氧，可选）
  repeat: Repeat          // 复用任务系统的 Repeat
  createdAt: string
}

// 完成状态按天独立，复用 occurrences 结构：key = `${itemId}@${date}`
```

### 交互

- 每条显示：`卧推  4 组 × 8 个` 或 `跑步  30 分钟 / 5 km`
- **整体勾一条**（已确认），不按组勾
- 有氧可以只填时长、只填距离，或两者都填
- 力量**不记重量**（已确认）
- 健身提醒仍按"整块"触发（最多 3 个时间点，繁忙时跳过），逻辑已有，不动

## 二、背景图（新需求 · ✅ 0.5.0 已完成）

- 设置页增加「背景」：从相册选择图片（`<input type="file" accept="image/*">` 在 Android WebView 里会打开相册/文件选择器）
- 选中后：**缩放到长边 ≤1600px** 再存（canvas），避免 IndexedDB 里塞进几 MB 原图
- 存 IndexedDB（`settings` 里放一个 `background` 记录：blob + opacity + blur）
- 渲染：`body::before` 固定定位铺满，`background-image` 用 blob URL，`opacity` 与 `filter: blur()` 由设置控制
- 两个滑杆：透明度 0–100%、模糊 0–24px，实时预览
- 「恢复默认」清掉背景，回到主题纯色
- 注意：主题的 `--bg` 仍然存在，背景图叠加在它上面，所以浅色/深色主题都能用

## 五、已知的技术坑（别重复踩）

- `Notification.Builder` 没有 `setSilent`（那是兼容库的）
- 通知频道的重要性创建后不可改，改设置要换频道 id（已在 0.4.1 用 `_v2` 处理）
- 静态资源改动后要同步改 `index.html` 里的 `?v=` 版本号，否则 WebView 可能用旧缓存
- 服务端（CI）打包安卓必须 JDK 21；本地构建要设 `JAVA_HOME/ANDROID_HOME/GRADLE_USER_HOME`
